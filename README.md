A one-line joke entry for the make.fun "One Line, One Laugh" bounty — a dependency-free Node program that writes the entry line to `entry.txt`.

> I told my smart fridge it was gaining weight — now it only opens for the salad and silently judges me every time I reach for the ice cream.

## Run it

```sh
node main.ts
```
